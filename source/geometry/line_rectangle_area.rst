直线/平面划分区域与网格单元的相交面积或体积计算
================================================

在有限体积法、嵌入边界方法或界面追踪方法中，经常需要计算一个规则网格单元有多少部分位于界面的一侧。
如果界面可以局部近似为直线或平面，那么问题就变成了半平面与长方形的相交面积，
或半空间与长方体的相交体积。

这类问题与圆、椭圆等曲线区域不同，不需要做数值积分。
由于直线和半平面都是线性几何对象，可以直接使用多边形裁剪得到相交区域，
再由多边形面积公式计算面积。
三维情况下也可以使用凸多面体裁剪来计算相交体积。


二维情况：直线划分区域与长方形的相交面积
------------------------------------------

设二维隐式直线函数为

.. math::

   \phi(x,y)=a x+b y+c

它将平面划分为正区域和负区域：

.. math::

   \Omega^+=\{(x,y)\mid \phi(x,y)\ge 0\}

.. math::

   \Omega^-=\{(x,y)\mid \phi(x,y)\le 0\}

长方形单元定义为

.. math::

   R=[x_1,x_2]\times[y_1,y_2]

其中 :math:`x_1<x_2`，:math:`y_1<y_2`。
直线划分长方形单元的几何关系如 :numref:`fig-line-rectangle-area` 所示。

.. _fig-line-rectangle-area:
.. figure:: fig/line_rectangle_area.png

    直线划分区域与长方形单元的相交区域


正区域与长方形的相交面积记为

.. math::

   A^+=|R\cap\Omega^+|

负区域与长方形的相交面积记为

.. math::

   A^-=|R\cap\Omega^-|

由于边界 :math:`\phi=0` 是一条直线，没有面积，因此把边界点分给正侧或负侧都不会改变最终面积。


半平面裁剪
^^^^^^^^^^

长方形可以看成一个按逆时针或顺时针排列的四边形：

.. math::

   P_1=(x_1,y_1),\quad
   P_2=(x_2,y_1),\quad
   P_3=(x_2,y_2),\quad
   P_4=(x_1,y_2)

对每个顶点计算符号值

.. math::

   \phi_i=\phi(P_i)

为了得到正侧多边形，需要用半平面 :math:`\phi\ge 0` 裁剪原来的长方形。
沿着多边形的每条边 :math:`P_iP_j` 依次处理：

#. 如果 :math:`\phi_i\ge 0` 且 :math:`\phi_j\ge 0`，则整条边在正侧，保留终点 :math:`P_j`。
#. 如果 :math:`\phi_i\ge 0` 且 :math:`\phi_j<0`，则边从正侧离开，保留交点。
#. 如果 :math:`\phi_i<0` 且 :math:`\phi_j\ge 0`，则边从负侧进入，先保留交点，再保留终点 :math:`P_j`。
#. 如果 :math:`\phi_i<0` 且 :math:`\phi_j<0`，则整条边在负侧，不保留点。

当一条边两端异号时，它与直线 :math:`\phi=0` 的交点可以用线性插值得到：

.. math::

   P=P_i+t(P_j-P_i)

其中

.. math::

   t=\frac{\phi_i}{\phi_i-\phi_j}

这是因为 :math:`\phi` 沿直线边是一次函数，
所以交点参数可以直接由两个端点的符号值线性确定。


多边形面积
^^^^^^^^^^

裁剪后得到的正侧多边形记为

.. math::

   Q_1,Q_2,\ldots,Q_m

其中 :math:`m` 可能为 :math:`0`、:math:`3`、:math:`4` 或更多。
如果 :math:`m<3`，则正侧没有正面积。
否则可用鞋带公式计算面积：

.. math::

   A^+=
   \frac{1}{2}
   \left|
   \sum_{k=1}^{m}
   \left(
   X_kY_{k+1}-X_{k+1}Y_k
   \right)
   \right|

其中 :math:`Q_k=(X_k,Y_k)`，并令 :math:`Q_{m+1}=Q_1`。

长方形总面积为

.. math::

   A_{\text{rect}}=(x_2-x_1)(y_2-y_1)

因此负侧面积可以由面积守恒得到：

.. math::

   A^- = A_{\text{rect}} - A^+


二维计算流程
------------

实际计算时，可以按如下步骤处理：

#. 检查输入是否满足 :math:`x_1<x_2`、:math:`y_1<y_2`，并且 :math:`a`、:math:`b` 不同时为零。
#. 构造长方形顶点 :math:`P_1,P_2,P_3,P_4`。
#. 计算每个顶点的符号值 :math:`\phi_i=a x_i+b y_i+c`。
#. 用半平面 :math:`\phi\ge 0` 裁剪长方形，得到正侧多边形。
#. 用鞋带公式计算正侧面积 :math:`A^+`。
#. 用 :math:`A^- = A_{\text{rect}}-A^+` 得到负侧面积。

这个流程自然覆盖以下退化情况：

#. 如果所有顶点都满足 :math:`\phi_i\ge 0`，则长方形完全在正侧，:math:`A^+=A_{\text{rect}}`，:math:`A^-=0`。
#. 如果所有顶点都满足 :math:`\phi_i\le 0`，则长方形完全在负侧，:math:`A^+=0`，:math:`A^-=A_{\text{rect}}`。
#. 如果直线只与长方形边界接触，接触点或接触线段没有面积，面积公式仍然成立。
#. 如果直线经过顶点或沿着一条边，令 :math:`\phi=0` 的点保留在正侧不会影响面积结果。


三维情况：平面划分区域与长方体的相交体积
----------------------------------------

三维情况下，隐式平面函数为

.. math::

   \phi(x,y,z)=a x+b y+c z+d

它将空间划分为正半空间和负半空间：

.. math::

   \Omega^+=\{(x,y,z)\mid \phi(x,y,z)\ge 0\}

.. math::

   \Omega^-=\{(x,y,z)\mid \phi(x,y,z)\le 0\}

长方体单元定义为

.. math::

   B=[x_1,x_2]\times[y_1,y_2]\times[z_1,z_2]

正半空间与长方体的相交体积记为

.. math::

   V^+=|B\cap\Omega^+|

负半空间与长方体的相交体积记为

.. math::

   V^-=|B\cap\Omega^-|

平面边界 :math:`\phi=0` 没有体积，因此边界点归属于哪一侧不影响最终体积。

三维问题可以看作二维半平面裁剪的推广。
长方体是一个凸多面体，用半空间 :math:`\phi\ge 0` 裁剪后仍然是凸多面体。
可以按如下思路计算 :math:`V^+`：

#. 构造长方体的八个顶点和六个面。
#. 对每个顶点计算符号值 :math:`\phi_i`。
#. 保留满足 :math:`\phi_i\ge 0` 的顶点。
#. 对长方体的每条边，如果边两端符号异号，则用线性插值求出平面交点。
#. 用保留顶点和交点重建被裁剪后的凸多面体。
#. 将凸多面体剖分为若干四面体，累加四面体体积，得到 :math:`V^+`。

边两端 :math:`P_i`、:math:`P_j` 异号时，交点仍然由

.. math::

   P=P_i+t(P_j-P_i),\quad
   t=\frac{\phi_i}{\phi_i-\phi_j}

给出。
长方体总体积为

.. math::

   V_{\text{box}}=(x_2-x_1)(y_2-y_1)(z_2-z_1)

于是负侧体积可由体积守恒得到：

.. math::

   V^- = V_{\text{box}} - V^+


三维计算流程
------------

实际计算平面与长方体的相交体积时，可以按如下步骤处理：

#. 检查长方体端点顺序有效，并且 :math:`a`、:math:`b`、:math:`c` 不同时为零。
#. 计算八个顶点处的符号值。
#. 如果八个顶点都在正侧，则 :math:`V^+=V_{\text{box}}`。
#. 如果八个顶点都在负侧，则 :math:`V^+=0`。
#. 其余情况，用半空间 :math:`\phi\ge 0` 裁剪长方体，得到正侧凸多面体。
#. 计算该凸多面体体积，得到 :math:`V^+`。
#. 用 :math:`V^- = V_{\text{box}}-V^+` 得到负侧体积。

这种方法同样覆盖平面穿过顶点、穿过边、与某个面重合或完全不穿过长方体等情况。
只要把 :math:`\phi=0` 作为边界处理，体积结果不会因为边界点归属而改变。


小结
----

直线把二维平面划分为正区域和负区域时，
长方形单元在正侧的面积可以通过半平面裁剪得到正侧多边形，再用鞋带公式计算；
负侧面积由长方形总面积减去正侧面积得到。

平面把三维空间划分为正半空间和负半空间时，
长方体单元在正侧的体积可以通过半空间裁剪得到凸多面体，再计算该多面体体积；
负侧体积由长方体总体积减去正侧体积得到。
由于直线边界没有面积、平面边界没有体积，边界点归属不会影响面积或体积结果。
