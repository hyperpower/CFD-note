椭圆/椭球与网格单元的相交面积或体积计算
========================================

在有限体积法、嵌入边界方法或界面追踪方法中，常常需要计算一个规则网格单元有多少部分位于某个椭圆或椭球区域内部。
二维情况下，这对应椭圆与长方形的相交面积；
三维情况下，则对应椭球与长方体的相交体积。

这类问题可以用几何切片的方式处理：
二维中沿一个坐标方向积分相交线段长度，三维中沿一个坐标方向积分相交线段长度并做二重积分。


二维情况：椭圆与长方形的相交面积
--------------------------------

设椭圆区域为

.. math::

   \frac{(x-c_x)^2}{a_e^2}+\frac{(y-c_y)^2}{b_e^2}\le 1

其中 :math:`(c_x,c_y)` 是椭圆中心，:math:`a_e` 是水平方向半轴，:math:`b_e` 是竖直方向半轴。
长方形单元定义为

.. math::

   x\in[x_1,x_2],\quad y\in[y_1,y_2]

椭圆与长方形单元的几何关系如 :numref:`fig-ellipse-rectangle-area` 所示。

.. _fig-ellipse-rectangle-area:
.. figure:: fig/ellipse_rectangle_area.png

    椭圆与长方形单元的相交区域


为了简化公式，将坐标系平移到椭圆中心处。令

.. math::

   X=x-c_x,\quad Y=y-c_y

则椭圆变为

.. math::

   \frac{X^2}{a_e^2}+\frac{Y^2}{b_e^2}\le 1

长方形区间变为

.. math::

   X\in[a,b],\quad Y\in[c,d]

其中

.. math::

   a=x_1-c_x,\quad b=x_2-c_x,\quad
   c=y_1-c_y,\quad d=y_2-c_y

对一个固定的 :math:`X`，只有 :math:`|X|\le a_e` 时椭圆内部才可能存在点。
此时椭圆内允许的 :math:`Y` 范围为

.. math::

   y_-(X)\le Y\le y_+(X)

其中

.. math::

   y_\pm(X)=\pm b_e\sqrt{1-\frac{X^2}{a_e^2}}

因此，在该竖向切片上，椭圆与长方形的相交线段长度为

.. math::

   L(X)=
   \max\left(
   0,\,
   \min(d,y_+(X))
   -
   \max(c,y_-(X))
   \right)

将该长度沿 :math:`X` 方向积分，就得到椭圆与长方形的相交面积：

.. math::

   A=\int_a^b
   \max\left(
   0,\,
   \min(d,y_+(X))
   -
   \max(c,y_-(X))
   \right)
   \,dX

实际计算时，积分区间可以限制为椭圆在 :math:`X` 方向的投影与长方形投影的交集：

.. math::

   X\in[\max(a,-a_e),\min(b,a_e)]


二维数值计算流程
----------------

二维椭圆与长方形相交面积可以理解为“竖向相交线段长度的积分”。常用计算步骤如下：

#. 将椭圆中心平移到坐标原点。
#. 将长方形区间变换为 :math:`X\in[a,b]`、:math:`Y\in[c,d]`。
#. 将积分区间限制到 :math:`[\max(a,-a_e),\min(b,a_e)]`。
#. 对每一个积分点 :math:`X`，计算椭圆内的 :math:`Y` 区间 :math:`[y_-(X),y_+(X)]`。
#. 将该区间与长方形的 :math:`[c,d]` 区间求交。
#. 对交线段长度 :math:`L(X)` 进行数值积分，得到相交面积。

如果长方形四个顶点都在椭圆内，则相交面积就是长方形面积。
如果长方形与椭圆没有交集，则相交面积为零。
其余情况可以使用上面的积分表达式计算。


三维情况：椭球与长方体的相交体积
--------------------------------

三维情况与二维情况类似，只是相交面积变为相交体积。
设椭球区域为

.. math::

   \frac{(x-c_x)^2}{a_e^2}
   +\frac{(y-c_y)^2}{b_e^2}
   +\frac{(z-c_z)^2}{c_e^2}
   \le 1

其中 :math:`(c_x,c_y,c_z)` 是椭球中心，
:math:`a_e`、:math:`b_e`、:math:`c_e` 分别是三个坐标方向上的半轴长度。
长方体单元定义为

.. math::

   x\in[x_1,x_2],\quad
   y\in[y_1,y_2],\quad
   z\in[z_1,z_2]

同样将椭球中心平移到坐标原点。令

.. math::

   X=x-c_x,\quad Y=y-c_y,\quad Z=z-c_z

则椭球变为

.. math::

   \frac{X^2}{a_e^2}
   +\frac{Y^2}{b_e^2}
   +\frac{Z^2}{c_e^2}
   \le 1

长方体区间变为

.. math::

   X\in[a,b],\quad Y\in[c,d],\quad Z\in[e,f]

其中

.. math::

   a=x_1-c_x,\quad b=x_2-c_x,\quad
   c=y_1-c_y,\quad d=y_2-c_y,\quad
   e=z_1-c_z,\quad f=z_2-c_z

对固定的 :math:`(X,Y)`，只有

.. math::

   \frac{X^2}{a_e^2}+\frac{Y^2}{b_e^2}\le 1

时椭球内部才可能存在点。
此时椭球内允许的 :math:`Z` 范围为

.. math::

   z_-(X,Y)\le Z\le z_+(X,Y)

其中

.. math::

   z_\pm(X,Y)=
   \pm c_e
   \sqrt{
   1-\frac{X^2}{a_e^2}-\frac{Y^2}{b_e^2}
   }

于是，在固定的 :math:`(X,Y)` 处，椭球与长方体在 :math:`Z` 方向的相交线段长度为

.. math::

   L(X,Y)=
   \max\left(
   0,\,
   \min(f,z_+(X,Y))
   -
   \max(e,z_-(X,Y))
   \right)

将该长度在 :math:`X-Y` 平面上积分，就得到椭球与长方体的相交体积：

.. math::

   V=\int_a^b\int_c^d
   \max\left(
   0,\,
   \min(f,z_+(X,Y))
   -
   \max(e,z_-(X,Y))
   \right)
   \,dY\,dX

该积分只有在椭球投影椭圆

.. math::

   \frac{X^2}{a_e^2}+\frac{Y^2}{b_e^2}\le 1

内才可能有非零贡献。


三维数值计算流程
----------------

三维椭球与长方体相交体积可以理解为“沿 :math:`Z` 方向的相交线段长度做二重积分”。常用计算步骤如下：

#. 将椭球中心平移到坐标原点。
#. 将长方体区间变换为 :math:`X\in[a,b]`、:math:`Y\in[c,d]`、:math:`Z\in[e,f]`。
#. 将积分区域限制到椭球在 :math:`X-Y` 平面上的投影椭圆内。
#. 对每一个积分点 :math:`(X,Y)`，计算椭球内的 :math:`Z` 区间 :math:`[z_-(X,Y),z_+(X,Y)]`。
#. 将该区间与长方体的 :math:`[e,f]` 区间求交。
#. 对交线段长度 :math:`L(X,Y)` 做二维数值积分，得到相交体积。

如果长方体八个顶点都在椭球内，则相交体积就是长方体体积。
如果长方体与椭球没有交集，则相交体积为零。
其余情况可以使用上面的二重积分表达式计算。


解析积分辅助公式
----------------

二维椭圆与长方形相交面积中，椭圆上半部分的积分可以通过变量代换转化为圆弓面积公式。
令 :math:`u=X/a_e`，则

.. math::

   \int b_e\sqrt{1-\frac{X^2}{a_e^2}}\,dX
   =
   \frac{a_e b_e}{2}
   \left(
   \frac{X}{a_e}\sqrt{1-\frac{X^2}{a_e^2}}
   +\arcsin\frac{X}{a_e}
   \right)

这个原函数可用于计算椭圆弓面积。
不过，对于一般位置的长方形，直接使用切片公式并进行数值积分通常更简单，也更容易推广到三维椭球情形。


小结
----

二维椭圆与长方形的相交面积可以通过竖向切片得到：
每个切片上先计算椭圆内允许的线段，再与长方形范围求交，最后对线段长度积分。

三维椭球与长方体的相交体积可以用同样思想处理：
对每一个 :math:`(X,Y)` 位置，先计算椭球内允许的 :math:`Z` 方向线段，再与长方体范围求交，最后做二重积分。
